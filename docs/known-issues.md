# 已知限制与未决项

更新：2026-11-15。已有 M0 骨架，产品链路未完成。
同日记入 Q-17。它来自竞品安装观察，不是新的上线阻断项。
“已确认限制”与“待实测”分别记录。

## 已确认的设计限制

| ID | 限制 | 当前处理 |
|---|---|---|
| L-01 | MailKit 无事后动作入口 | 设计采用 MailBridge |
| L-02 | MailKit 无自定义邮箱移动 | 自动化权限提前到 P0 |
| L-03 | MailKit 无账户、邮箱、selection 查询 | 不推断账户；桥接定位 |
| L-04 | 扩展不能修改草稿正文 | 宿主预览与交接 |
| L-05 | 扩展无原旗标快照 | 不写排队旗标 |
| L-06 | Mail 无跨字段事务保证 | 分动作回执，显示部分完成 |

## 阻断自动整理上线的待验证项

| ID | 问题 | 验证 / 所有者 | 解除条件 |
|---|---|---|---|
| Q-01 | 宿主与沙盒扩展能否可靠交接 | M0-01 / Mail 集成 | 签名原型通过 |
| Q-02 | 邮件能否唯一映射到账户与对象 | M0-03 / Mail 集成 | 重复与缺失 ID 不误写 |
| Q-03 | Apple Events 回执能否稳定核验 | M0-05 / Mail 集成 | 中断和移动后定位通过 |
| Q-04 | Harness 能否真正禁止工具与全局执行 | M0-07/08 / Adapter | canary 与副作用测试通过 |
| Q-05 | 自动化使用是否符合提供商条款 | M1 / 产品发布 | 按提供商记录当前条款结论 |
| Q-06 | 暂停、撤权、取消是否阻止后续写入 | M0-09 / 核心 | 无迟到动作 |

Q-02 另有未验证的私有库候选，记在 Q-17。
该候选不改变 Q-02 的解除条件。
