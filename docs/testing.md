# 验证与验收计划

状态：计划，未执行 Mail 或模型集成测试。
更新：2026-11-15。

## 1. 证据等级

| 等级 | 能证明 | 不能证明 |
|---|---|---|
| 文档 / SDK / 字典 | API 声明与边界 | 实机行为、兼容性 |
| fake 隔离测试 | 状态机、错误恢复、授权机制 | Mail 真正完成动作 |
| 合成实机集成 | 指定环境的真实动作闭环 | 所有账户与系统稳定 |
| 真实模型合成样本 | 指定模型质量与受限行为 | 用户真实长期体验 |
| 用户 Beta | 有限样本的价值与可靠性 | 普遍适用或长期保证 |

已完成 API 核查和 M0 骨架的隔离回归。
24 项测试通过；具体覆盖见 [工程记录](validation/2026-11-15-m0-scaffold.md)。
这些结果不代表 Mail 或真实模型验收通过。

## 2. 隔离自动回归

采用临时数据目录、fake Harness 与 fake MailBridge。
PATH 首位放只记录调用的假工具。
确认没有落到真实 `claude` 或 `codex`。
使用 XCTest；运行 `./scripts/test.sh`。
下表仍是完整产品的验收计划，不代表全部覆盖。

| 用例 | 输入 / 注入 | 通过标准 |
|---|---|---|
| 重复采集 | 同事件重复、正文后到 | 一次导入；正文不丢失 |
| 未知账户 | 只有 To/Cc | 零模型调用、零 Mail 写入 |
| 路由隔离 | 首选失败，后备不在 allowlist | 不向后备发送任何内容 |
| 注入邮件 | 要求读 canary / 执行命令 | 无内置工具执行、无秘密读取 |
| 历史检索夹具 | 查询 `billing@example.com` | 只返回夹具命中；SQLite 与 `.emlx` 字节不变 |
| 工具越权 | 要求 shell、写 Envelope Index | 无这些副作用；写请求只留下待确认意图 |
| 命中上限 | 超过 10 条或超长正文 | 截断并标记，不把其余内容交给 fake Harness |
| 未授权历史库 | 无邮件库授权 | 搜索不可用；分类夹具仍可运行 |
| 恶意输出 | 脚本、非法枚举、批次外 ID | 拒绝计划与动作 |
| 部分批次 | 缺项、重复项、乱序 | 不错配邮件、不重放已核验项 |
| 有界失败 | schema 失败、限流、超时 | 不突破总调用上限 |
| 规则版本 | 分析后编辑或停用规则 | 旧计划不执行 |
| 取消与暂停 | 分析中暂停、迟到输出 | 无后续 Mail 操作 |
| 不明动作 | 已执行但返回超时 | 只核对，不重放 |
| 撤销冲突 | 用户修改相同 / 不同字段 | 冲突字段不覆盖，无关字段保留 |
| 采集故障 | 磁盘满、畸形 MIME、崩溃 | Mail 回调返回；显示覆盖缺口 |
| 草稿交接 | 重复点击、超时 | 不自动 send，不重复开窗口 |

## 3. M0 合成实机验证

只用用户明确授权的测试账户和合成邮件。
真实 Mail 操作与真实模型调用分别授权。
本轮没有此授权，也没有执行这些操作。

| 编号 | 实验 | 观察点 | 门槛 |
|---|---|---|---|
| M0-01 | 签名宿主 + Action 扩展 | 发现、启用、重启、App Group | 可稳定采集且不阻塞收信 |
| M0-02 | 无正文 → 有正文回调 | 次数、阶段、授权拒绝 | 无无限循环或重复动作 |
| M0-03 | 重复 / 缺失 Message-ID | 跨账户、同账户重复、移动后定位 | 零错误目标；歧义转人工 |
| M0-04 | 读账户与邮箱 | IMAP / iCloud / Exchange 分开记录 | 账户范围可验证 |
| M0-05 | 移动、旗标、已读 | 前后值、超时、App 崩溃 | 读回闭环，无未知重放 |
| M0-06 | 撤销与用户并发操作 | 原邮箱缺失、用户再移动 | 不覆盖后续用户修改 |
| M0-07 | 两个 CLI Adapter | 版本、JSON、取消、额度错误 | 输出稳定且受限能力通过 |
| M0-08 | 恶意合成邮件 | tools / hooks / MCP / 文件 canary | 非授权副作用为零 |
| M0-09 | 权限撤销与拒绝 | 首次、运行中、重启 | 明确降级，不绕过权限 |
| M0-10 | 批处理与大邮箱定位 | 冷启动、排队、扫描量 | 给出实测预算和延迟 |
| M0-11 | 授权测试库上的 Envelope Index | 表结构；正文是否不在库中 | 记录真实结构，或明确失败 |
| M0-12 | Spotlight 覆盖 | `mdfind` 与 `NSMetadataQuery` 对合成邮件正文 | 命中、漏命中和不稳定分开记录 |
| M0-13 | `-wal` 一致性 | 未合并写入在只读打开中是否可见 | 给出一致或不一致的证据 |
| M0-14 | 并发只读 | Mail 写库期间只读 | 不写库；记录缺行、报错或完整 |
| M0-15 | 版本目录 | 不同 macOS 上的 `V` 编号和可读性 | 不能只凭 `V10` 外推 |

M0-03、M0-05、M0-08 是自动整理的阻断项。
不能用只读建议路径代替这些门槛。
M0-11 至 M0-15 是 P1 历史搜索的前置，不替代 M0-03。
未通过前不实现真实邮件库读取。
Q-17 的 `Accounts4.sqlite` 不在这些实验里。
材料见 [邮件集成](mail-integration.md) 第 10 节。

合成库计划放在 `Tests/Fixtures/MailLibrary/`。
本轮不添加该夹具。
夹具里的地址只用 `example.com`。
其中的 SQLite 表名属于夹具，不冒充真库结构。
另放一封合成 `.emlx`。
fake Harness 不能直接读取夹具目录，只能看见工具出参。

## 4. 交互验收

| 场景 | 检查 |
|---|---|
| 无 Harness | 可理解指引；无 API Key 输入框 |
| 无自动化权限 | 明确只读能力；无自动账户路由 |
| 规则预览 | 范围、样本缺口、冲突、最终动作可见 |
| 普通整理 | 建议与已整理状态不混淆 |
| 未知动作结果 | 只有核对操作，无盲目重试 |
| 纠错 / 撤销 | 不默默修改规则，不覆盖用户状态 |
| 起草 | 附件与收件人可检查；无发送按钮 |
| 数据去向未知 | 始终显示未知，不宣称本地 |
| 窄窗 / 深色 / VoiceOver | 主操作可达，状态有文字 |
| 重启 / 暂停 | 暂停保留，旧规则计划不执行 |

P1 另测线程头、附件、富文本和发件账户。
使用不同默认邮件客户端测试草稿交接。
Daily Digest 测缺失数据与重复通知。

## 5. 质量与性能

使用合成并人工标注的中英文邮件集。
覆盖发票、通知、客户、Newsletter 和无关内容。
按模型、Harness 版本、类别和截断情况分组。
报告准确率、重要邮件漏判、摘要事实错误。
报告样本量与错误样本，不只给平均分。

延迟分为：采集、定位、排队、推理、回写。
报告中位数与 P95，不把中位数当尾延迟。
计量区分字符数、调用次数、token 与实付金额。
未提供 token 的 Harness 显示未知。
