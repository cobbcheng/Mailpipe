# OpenClaw 与 Hermes Agent 合成草稿验收

系统为 macOS 27.0.1 arm64，SDK 为 27.2。
候选菜单栏 App 和扩展为 0.0.6（build 33）。
App 使用 Apple Development 签名，实测前后签名校验通过。

## 起草结果

两个 CLI 均安装在专用临时目录。
OpenClaw 2026.11.5 使用原生 DeepSeek 认证存储。
Hermes Agent 0.23.2 使用官方源代码安装器的启动器及默认配置下的 `.env`。
它们各自登录并使用官方 DeepSeek Flash。

每项先用引导的试写路径处理合成邮件。
另在全新目录预置一封带独立授权的合成来信。
启动候选 App，由宿主恢复队列并生成回复。
两次均持久化到 `draftReady`。
草稿引用与来信匹配，正文均确认已收到项目简报。
每条记录包含所选 Agent、模型及 `deepseek-official`。
两次均未写入用户的正式队列。

OpenClaw 回执报告 `deepseek/deepseek-flash`。
Hermes 从服务响应确认 `deepseek-flash`。
输入字符按传给适配器的 JSON 统计。
输出字符按返回的草稿 JSON 统计。
实付金额未报告。OpenClaw 的助手轮数不含底层 HTTP 重试计数。

## 验证边界

仅用合成主题、正文和独立授权。
本次没有连接邮箱账户、发送邮件或切换用户的活动授权。
未复测 Apple Mail 实际投递、撰写窗口或全新 Mac 的首次授权。
CLI 的临时状态隔离不等于操作系统级沙盒。

OpenClaw 的四次本地模拟调用使用假供应方。
模拟服务观察到空工具列表。缺少密钥另经原生认证探测。
普通起草禁用插件、技能和其他模型回退。
该 CLI 仍会添加自己的运行上下文。
Hermes 在发送前核对官方端点、模型、消息和工具列表。
普通起草不启动 Hermes Gateway。

隔离回归通过 110 项。运行时 69 项、适配器 36 项、回复契约 5 项。
自动回归中的真实 Harness 调用为零。

最终 Hermes 运行时另以离线 HTTP 响应验证成功、认证失败、余额不足、限流和超时。
两项 Hermes 回归含 11 个模拟运行场景。
两种 Agent 的六次云端起草共报告输入 7,962、输出 696 token。
Hermes 另查询一次官方模型列表，该查询没有 token。
两套临时安装、测试用原生凭据、依赖缓存和共享测试密钥均已清理。
