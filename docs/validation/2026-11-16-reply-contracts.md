## 实机模型验收

新增命令仅支持固定合成样本：

```sh
./scripts/swift.sh run mailpipe-m0 reply-probe \
  "$(command -v dsh)" "$VALIDATION_OUTPUT_DIR"
```

输出目录须是尚不存在的绝对路径。
命令最多调用模型两次，消耗用户额度。
调用前写入记录，完成或失败后更新。
此机制只供探针验收，不是生产任务队列。

样本来自 `ReplySyntheticFixture`。
合成同事请求确认收到项目简报。

| 调用 | 结果 | 输入 token | 输出 token | 输入字符 | 输出字符 | 耗时 |
|---|---|---:|---:|---:|---:|---:|
| 分拣 | `should_reply=yes`，证据匹配原文 | 486 | 432 | 1494 | 585 | 3.23 秒 |
| 草稿 | 合法草稿，关联 ID 正确 | 378 | 235 | 1084 | 248 | 2.80 秒 |

模型调用共 2 次；版本和帮助检查不算模型调用。
token 来自 Harness usage，不由字符数估算。
输入字符是应用提交的提示词和 JSON 字符数。
输出字符是最终 JSON 文本，不含思考过程。
实付金额未知；未读取账单或推算订阅费用。
两次调用都有不同 run ID 和去向记录。
工具注册表及模型可见工具列表均为空。
草稿是简短确认收到的回复，没有新增承诺。
没有打开撰写窗口或写入 Mail 草稿邮箱。
