## 实现与机制

| 模块 | 所有者与触发 | 幂等与恢复 | 外部效果 |
|---|---|---|---|
| 入站暂存 | MailKit 新邮件回调 | 原子发布；独立 ingest ID | 仅写本机 App Group |
| 正文请求 | 扩展，正文缺失时 | 持久化一次性 claim；同一授权内不循环请求 | MailKit 正文重入 |
| 导入 | 宿主，每两秒检查 | SQLite 提交后删除文件；ingest 去重 | 无网络 |
| 账户核验 | 宿主，队列派发前 | 限定账户和邮箱，唯一匹配并比对邮件源 | 只读 Apple Events |
| 分拣 / 草稿 | 宿主，串行派发 | 调用前持久化；未知结果不自动重试 | 每阶段一次模型调用 |
| 数据库写者 | 宿主进程 | 同目录非阻塞独占锁；第二个宿主拒绝启动 | 不修改 Mail |
| 待处理 | 菜单栏与工作台 | 从同一 SQLite 状态读取 | 不自动弹窗或发送 |

新增机制对应两个实际中断点。
宿主退出时，MailKit 仍可能采集。
模型调用开始后，进程退出会丢失返回结果。
因此待调用状态可恢复，调用中状态转为待核对。
独占锁防止测试 CLI 与 App 同时派发同一数据库。
它不增加后台服务、自动回退或模型重试。

数据库只有 records、ingests、metadata 三张表。
单条记录内的任务、结果和调用证据原子保存。
它不是完整 ActionIntent 或规则数据库。

## 隔离回归

```sh
./scripts/test.sh --filter 'PipelineTests|ReplyContractTests|ReplyProbeTests|AdapterTests|ProcessRunnerTests|BodyProbeTests|IdentityQueryTests'
```

46 项通过，真实 Harness 调用日志为空。
回归使用临时目录和 fake Harness / 身份解析器。
不连接真实模型或 Mail。

覆盖以下行为：

- 同一 ingest 重放不重复导入。
- 正文重入合并到唯一的空候选。
- 账户、locator、内容相同的回调不重复调用模型。
- 分拣完成后重启，只接续草稿阶段。
- 调用中断后转待核对，不自动重放。
- 暂停、撤权、未知账户阻止派发。
- 调用中暂停后，不采用结果或继续起草。
- L0、L1、no、unknown 不生成 L2 草稿。
- 第二个数据库写者被拒绝。
- 符号链接输入被拒绝，目标文件不被删除。
- 复杂 MIME 被拒绝，quoted-printable 可解码。
- 派发前再次检查授权；正文只走 stdin。

`pipeline-seed` 写入固定合成样本后退出。
命令没有调用模型或 Mail。
签名 App 使用该私有目录启动。
App 完成分拣和草稿，显示“草稿已备好”。
正常退出并重启 App 后，草稿仍在。

./scripts/swift.sh run mailpipe-m0 pipeline-seed \
  "$(command -v dsh)" "$VALIDATION_OUTPUT_DIR"
open .build/xcode/Build/Products/Debug/Mailpipe.app \
  --args --pipeline-directory "$VALIDATION_OUTPUT_DIR"

它不能给任意入站文件伪造账户授权。

它们对应无正文阶段与正文重入阶段。
宿主重开后，两个 ingest 合并为一条记录。
该记录的 `syntheticAuthorized` 为 false。
它经过正式账户核验，而非测试身份捷径。

账户和 locator 已唯一匹配。
完整 RFC822 源在规范化换行后摘要相同。
分拣返回 yes；草稿进入本机待处理。
工作台显示原主题、草稿、状态和两次去向。
没有打开撰写窗口或写入 Mail 草稿邮箱。

## 构建和限制

隔离回归与实机验收分开执行。
`./scripts/build-app.sh` 完成签名构建。
宿主与扩展的 strict 签名校验通过。
构建时曾遇到遗留 `.cstemp` 签名中间文件。
清理生成目录内的该中间文件后构建成功。
未改权限、凭据、Hardened Runtime 或沙盒边界。

当前正文只支持单段 text/plain。
支持 UTF-8 / ASCII 和 identity、base64、quoted-printable。
HTML、multipart、附件及其他编码转待核对。
原文超过 64 KiB，或正文超过 16 KiB，也转待核对。
不存在可靠身份时，不调用模型。
核验失败后需用户点“重新核验账户”。
这不重放已执行或结果未知的模型调用。

暂存上限 500 条，正文 claim 上限 500 个。
SQLite 当前上限 1000 条邮件记录。
达到上限后停止接收或导入，并显示采集缺口。
正文七天后不再派发；暂存超过一天拒绝导入。
完整的自动清理与数据管理 UI 尚未实现。
宿主退出期间不承诺按时删除到期文件。

L0 整理动作、规则、条件撤销和草稿交接未实现。
不承诺睡眠处理、24 小时在线或生产分拣准确率。
未推送、未创建 PR、未发布安装包。
本机测试 App 已更新，验证结束后保持暂停。
