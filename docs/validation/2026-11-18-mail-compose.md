# Mail 撰写交接验收

状态：合成邮件的撰写交接、编辑、重新生成及失败保留已实机验收。

## 设计与边界

- 仅用户主动点击才准备交接，模型没有此工具。
- 从已授权收件箱重新定位原信并核对来源。
- 收件人使用原信 Reply-To，缺失时使用 From。
- 畸形或歧义地址拒绝，不从模型输出猜收件人。
- 原账户发件地址必须唯一归属该账户。
- 确认预览包含账户、发件人、收件人、主题与正文。
- 确认后重查暂停、撤权、丢弃及编辑变化。
- 持久意图先于外部操作；未知结果不自动重放。
- 仅新建撰写窗口，不发送，不声称保留原邮件线程。
- 每封记录一次交接；后续编辑由用户在 Mail 中进行。
