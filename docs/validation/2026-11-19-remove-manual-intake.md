# 移除手动添加来信

## 隔离回归

`scripts/build-app.sh` 构建通过。
`scripts/test.sh --filter MailpipeRuntimeTests` 通过 63 项。
测试使用临时队列与假 Harness，真实 Harness 保护日志为空。
旧手动任务在重开队列时停止派发。
旧手动授权不能用于重新生成草稿或接收 MailKit 来信。
用户重新确认后可授权 MailKit，已有暂停状态保留。

## 合成数据实机验收

使用 Apple Silicon、macOS 27.0.1 和 SDK 27.2。
以下用例使用独立测试宿主及临时队列。
账户、旧版设置和邮件均为合成数据。

| 场景 | 观察结果 |
|---|---|
| 已授权 MailKit 的工作台 | 直接展示邮件和草稿，未出现添加来信入口 |
| 旧版手动模式已完成设置 | 可打开历史草稿，编辑后重启仍可读回 |
| 旧版手动模式尚未完成设置 | 回到扩展确认步骤 |
| 设置中的新来信授权 | 在来信处理页确认范围。通用页不能首次授权 |

上述界面用例的假工具调用为零。
