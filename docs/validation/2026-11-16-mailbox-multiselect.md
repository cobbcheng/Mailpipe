# 邮箱发现与多选

日期：2026-11-16。测试包 build 5。

## 改动

第四步从文本输入改为账户分组的复选框。
自动读取账户与邮箱名称，不读取邮件内容。
支持跨账户、同账户多邮箱与嵌套层级。
Mail 会重复枚举部分子邮箱，按真实路径去重。
读取失败保留草案，提供主动刷新入口。
失效选择不被静默替换，最终确认前重新核验。

选择集合独立保存，不改变当前生效范围。
最终确认原子保存整个集合，保留暂停状态。
派发前只在授权集合中核验邮件。
唯一匹配才能交给模型，多处匹配转待核对。
旧单邮箱配置与旧队列仍可读取。
旧草案中的手填名称不会自动变成新授权。

## 验证

18 项隔离回归通过。
使用临时数据库、fake Harness 和 fake MailBridge。
覆盖第二个所选账户命中、跨范围歧义禁止派发。
覆盖多选原子生效、暂停保留与旧单范围兼容。
邮箱发现与路径查询脚本编译通过。
没有调用真实模型或发送测试邮件。

原生 App 在本机发现三个已配置账户。
实际显示嵌套路径及默认未勾选状态。
实测修复子邮箱重复出现和顶层容器边界。
多选保存与授权逻辑通过隔离回归。
本轮未重新验收多个真实邮箱的完整收信链路。
原生多选点击验收受到系统截图接口错误影响。
不把隔离回归当作完整原生点击验收。
