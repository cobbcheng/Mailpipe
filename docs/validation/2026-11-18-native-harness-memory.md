# 原生 Harness 上下文验收

## 实际能力与边界

当前回复运行器支持 DSH 0.2.2-rc.1。
本机该版本的原生持久上下文入口是全局 AGENTS.md。
分别位于用户的 `.dsh` 与 `.agents` 根目录。
不是 Codex 或 Claude Code 的 auto-memory。
本机上述两个文件均不存在，因此当前个人化会中性降级。
不能把合成验证说成读取了真实个人记忆。

旧实现禁用了 agent-instructions，且每次使用隔离 DSH_HOME。
仅在提示词中写“使用已有记忆”不能证明加载发生。
本次恢复原生插件，只开放两个原生全局指令文件。
每个文件限 16 KiB，仅常规文件及有效 UTF-8。
符号链接、超限、缺失或读取失败均不加载。
快照仅在本次临时工作区存在，退出即清理。
不创建画像库、不改写原文件、不读取或复制凭据。

项目指令候选及项目根搜索关闭，技能、文件工具继续关闭。
原生全局上下文只用于措辞和语气，不能充当邮件事实。
系统边界要求不披露上下文、不作虚构承诺、不执行外部动作。
注册及广告工具列表仍必须为空，模型请求严格限一次。
宿主原有账户授权、输出 schema 和实时暂停检查不变。
