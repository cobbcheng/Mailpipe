# 菜单栏打开工作台

2026-11-19，本机签名 build 20 已通过点击验收。

## 卡顿与修复

build 19 主线程采样覆盖了两条慢查询。
后台队列同步等待收件箱核验。
工作台可见行同步等待旧邮件地址补齐。
等待 Apple Mail 期间，界面无法及时处理点击。
工作台打开后，菜单弹窗还会遮住窗口。

宿主现在按需启动同一签名程序的只读子进程。
AppleScript 在子进程主线程执行。
每次查询增加一次本机进程启动。
查询串行执行，参数和结果通过有界管道传递。
子进程只接受同一宿主发起的读取。
超时沿用现有失败处理；子进程不打开队列。

宿主仍负责核验来源、账户与处理范围。
等待结束后重新检查授权与当前记录。
菜单选择来信或打开工作台时会收起弹窗。

## 验证范围

| 环境 | 操作 | 结果 |
|---|---|---|
| 临时目录与假工具 | 延迟返回、取消排队、读取大于管道容量的结果 | 单个查询等待时主线程仍可处理事件 |
| 临时队列 | 查询期间编辑、丢弃、取消、暂停或换授权 | 迟到结果保留用户操作，旧记录不会查询新授权账户 |
| 签名 App 与合成记录 | 分别点击打开工作台、菜单最近项 | 弹窗关闭，最近项选中正确的合成记录 |
| 本机安装包 | 后台查询期间从菜单弹窗点击打开工作台 | 约 0.32 秒后确认工作台在前台，弹窗已关闭 |

实机使用 macOS 27.0.1、macOS SDK 27.2。
沿用现有账户的收件箱授权。账户服务商未核验。
安装前已确认队列无在途派发，并私有备份旧包与数据。
宿主与扩展均保留原签名、权限及双架构。
核对时设置、既有草稿和模型运行记录一致。

Runtime 和 MailBridge 共 78 项隔离测试通过。
真实 Harness 保护日志为空。
实机验证期间未新增模型调用，也未发送邮件。
