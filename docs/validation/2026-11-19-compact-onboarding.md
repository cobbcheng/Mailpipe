# 紧凑新手引导与工作台入口验收

## 环境

macOS 27.0.1，Xcode 27.2，macOS SDK 27.2。
通过 `scripts/build-app.sh` 构建宿主与扩展。
界面验收使用独立标识的临时宿主副本。
队列使用 `--pipeline-directory`，工具为假 `dsh`。
未配置测试邮箱，也未启用真实 Mail 扩展。

## 隔离回归

`scripts/test.sh --filter Onboarding` 通过 10 项。
覆盖设置草案、测试证据失效、最终授权及暂停保留。
新增用例检查草案和设置不能绕过首次授权。
已完成用户修改配置失败时，原授权继续有效。
测试脚本记录的真实 Harness 调用为零。

## macOS 窗口验收

| 操作 | 实际结果 |
|---|---|
| 从空队列交互启动，带 `--open-workbench` | 仅出现欢迎页。默认窗口实测 480 × 442 pt，含标题栏 |
| 稍后继续，从 Dock 重开或按 ⌘1 | 恢复原步骤，没有出现草稿列表 |
| 从菜单栏打开；从 App 设置窗口继续 | 回到同一向导；首次设置前菜单不展示草稿 |
| 中断后重启 | 恢复第 5 步，连接测试没有重复执行 |
| 选择多个工具中的一个 | 能按安装路径选择；最终复核显示目标路径 |
| 逐封模式改为自动处理 | 缺少扩展确认时，返回扩展步骤 |
| 手动确认扩展，无运行回执 | 显示仍待验证；缺少共享容器时不能授权自动处理 |
| 最终复核时假工具报告不兼容版本 | 停在复核页，持久化完成标记仍为假 |
| 恢复工具后确认逐封建议 | 显示保存回执；点击后进入工作台 |
| 用已完成队列重启 | 直接打开工作台，并恢复调整过的窗口尺寸 |
| 恢复大工作台窗口位置，切换为空队列 | 仅显示引导，外框收回至 480 × 472 pt |
| 旧版草案未完成，同时有生效授权 | 可从 App 设置暂停和撤权；引导仍未完成 |
| 深色外观，450 pt 窄窗 | 插图、说明、返回与主按钮可见 |

五份资源均由构建产物内的 Lottie 4.6.1 加载。
每份动画播放 1.6 秒，起始帧与运动帧有变化。
静止末帧在浅色和深色背景下均可见。
VoiceOver 完整朗读和系统级“减弱动态效果”切换未实测。
