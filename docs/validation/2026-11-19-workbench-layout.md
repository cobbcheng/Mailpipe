# 工作台布局验收

## 合成数据实机验证

环境为 Apple Silicon、macOS 27.0.1、SDK 27.2。
候选 App 为 0.0.4（26）的本地 Debug 构建。
测试宿主使用独立标识和临时队列。
来信、草稿和地址均为合成数据。
测试使用手动粘贴模式和假 Agent，无邮箱授权。

| 场景 | 实测结果 |
|---|---|
| 900 × 580 pt 默认窗口 | 提示、主题、正文与发送按钮共用左边距。五个操作均在短稿首屏可见 |
| 660 pt 宽窗口 | 分栏宽度与窗口一致。按钮根据可用宽度分成两行 |
| 侧栏拖宽至 340 pt | 五个操作均可见。点第二行的信息按钮能打开数据去向 |
| 在同一草稿内编辑 | 一行输入增至 24 行，再删回一行，编辑区从 55 增至 412 pt，再回到 55 pt |
| 清空草稿 | 点击空白编辑区的下半部，可继续输入 |

最初在 280 pt 编辑宽度直接跳到长稿末尾时，
最后几行曾与操作重叠，或和操作相距过远。
现由独立文本容器测量，编辑器按实际宽度换行。
复测直接跳到底部可见第 21 段、末行和操作按钮。
