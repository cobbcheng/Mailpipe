# 账户多选与自动收件箱

日期：2026-11-16。测试包 build 6。

## 交互修正

用户要求选择邮箱账户，而非邮箱文件夹。
每个账户一个复选框，可同时选择多个账户。
选中后自动关联该账户的收件箱。
第五步只显示账户和“收件箱”，不展示目录树。

通过 Apple Mail 的系统 inbox 对象发现映射。
不猜测 INBOX、收件箱等名称或供应商规则。
同一账户只允许一个系统收件箱。
最终确认重新核验映射，再原子保存授权。
发现和勾选不授权外发，不改变已生效策略。
旧版文件夹草案不能悄悄转成账户授权。
失效旧选择需移除，或重新勾选该账户。

## 验证

19 项隔离回归通过，无真实 Harness 调用。
补充同一账户不能授权多个位置的测试。
原有跨账户唯一匹配、歧义拒绝与暂停保持仍通过。

独立只读实机命令：

```sh
./scripts/swift.sh run mailpipe-m0 inbox-probe
```

本机发现三个账户，各映射一个系统收件箱。
命令仅读取账户与收件箱元数据。
不读取邮件内容、不调用模型、不修改 Mail。

原生界面实测只有三个账户复选框。
在隔离数据目录中同时勾选两个账户。
第五步正确显示两个账户，各自对应“收件箱”。
草案保存了两个位置，未生成生效授权。
未修改用户正式设置或试用进度。
