# Apple Mail 回复工具栏实机验收

以下记录覆盖 0.1.7 的本地候选版本。
测试系统为 macOS 27.0.1，使用 macOS SDK 27.2。
宿主与扩展均使用 Apple Development 签名。

## build 43 原生交互

在真实 Mail 打开合成 EML，按 ⌘R 打开回复。
工具栏默认显示 Mailpipe。点击可打开原生面板。

| 操作 | 观察结果 |
|---|---|
| 打开合成邮件的回复建议 | 与预置草稿正文一致 |
| 在面板输入，再关闭和重新打开 | 编辑内容保留 |
| 连续点击工具栏图标 | 面板能关闭、重新打开并完成查询 |
| 点击「用 … 改短」 | 指定的 fake 工具收到编辑后的文字，返回较短正文 |
| 点击「复制回复」后在同一个回复窗口按 ⌘V | 同时读回改短后的正文与原文引文 |
| 关闭测试回复 | 丢弃合成草稿，恢复原剪贴板 |

有建议的实机测试使用独立数据库与预置草稿。
临时中继仅转递该合成邮件的请求。
临时授权只覆盖该主题和指定的 fake 工具。
未使用收件账户投递样本。真实模型改写质量未验证。

两轮界面测试各调用 fake 工具一次。
每次输入 997 字符，输出 271 字符。
fake 工具未报告 token。面板测试的真实模型调用 0 次，实付 0。
测试未发送邮件。

恢复正式宿主并关闭临时中继后，再打开同一份 EML。
正式队列没有这封邮件。面板直接显示「这封邮件还没有可用的回复建议。」
