# 产品方案

状态：基于 PRD v0.3 的工程化草案。
更新：2026-11-15。来源见 [来源](sources.md)。
本文件不替换或修改原 Notion 文档。
优先级调整属于本轮建议，尚未经产品实测。

## 问题与目标

| 问题 | 用户结果 |
|---|---|
| 收件箱噪音多 | 快速找到需行动的邮件 |
| 原生规则难以表达语义 | 用一句话描述整理意图 |
| 已有 Harness 尚未接到邮箱 | 复用已有配置与认证 |

首要用户：已使用 Harness 的技术型 Mac 用户。
次要用户：已装 Harness 的高邮件量用户。
不面向尚未配置 Harness 的大众市场承诺开箱即用。

## 范围与验收

| 级别 | 能力 | 验收结果 |
|---|---|---|
| P0 | 新邮件采集与恢复 | 宿主重启后接续；重复回调不重复执行 |
| P0 | 两个 Harness Adapter | 分别验证无头、受限模式、结构化输出 |
| P0 | 分类与摘要 | 五类 + 未分类；≤3 行摘要；列出依据 |
| P0 | 自然语言规则 | 保存前预览；语义不支持时明确拒绝 |
| P0 | 自动整理 | 仅授权账户；唯一定位；执行后读回 |
| P0 | 日志与条件撤销 | 看见原值、新值、规则与结果；冲突不覆盖 |
| P0 | 账户路由与暂停 | 禁止未授权回退；暂停后无新动作 |
| P0 | 签名直装 | 在干净测试环境验证安装与权限 |
| P1 | Daily Digest | 有覆盖区间与缺口；可定位来源 |
| P1 | AI 起草 | 预览后交给 Mail；App 不调用 send |
| P1 | 更多 Adapter | 按版本建立独立安全验收 |
| P1 | 用量面板 | 调用、耗时、失败分开；缺失 token 显示未知 |
| P2 | 白名单发送 | 另立设计，不复用 P1 的发送授权 |
| P2 | 日历、待办、规则分享 | 尚未设计，不作为当前交付 |

分类模型采用两个维度。
`category` 是客户、账单、通知、Newsletter、其他。
`needs_action` 独立表示需要行动。
“重要/待回复”是视图，不与业务类别互斥。
模型无法判断时输出 `unknown`，不强制归类。

## 与 PRD v0.3 的差异

| 原设计 | 本轮修订建议 | 原因 |
|---|---|---|
| MailKit 后续回写分类动作 | Apple Events 执行与核验 | 无公开事后回写 API |
| 自动化权限仅在 P2 申请 | P0 自动整理即申请 | 自定义邮箱和异步动作依赖桥接 |
| 在 Mail 打待处理旗标 | 待处理只在 Mailpipe 显示 | 无法可靠保存和恢复原旗标 |
| 日志与撤销在 P1 | 提前到 P0 | P0 已经自动改动邮件 |
| 按账号指定 Harness 在 P1 | 最小账户路由约束提前到 P0 | 防止回退改变数据去向 |
| 选中邮件即有摘要 | 明确 App 选中与 Mail 选中两种入口 | MailKit 无 selection API |
| 自然语言规则全部本地确定执行 | 区分字面条件和模型语义条件 | “发票”等概念需要语义判断 |
| 未纠正比例等于准确率 | 单列纠错率与标注准确率 | 未纠正不证明正确 |

## 明确不做

不做新邮件客户端、SMTP 或服务商直发。
不接管模型账户，不替用户登录 Harness。
不索引整个硬盘，不读取 Mail 私有数据库。
不通过安全扩展伪装 AI 摘要横幅。
不将后台摘要结果直接变成发送行为。

## 体验成功标准（假设）

| 指标 | 设计目标 / 测量方法 |
|---|---|
| 激活 | 24 小时内完成授权并处理一封合成邮件；目标 60% |
| 分类 | 标注样本准确率目标 90%；同时报告样本量与类别 |
| 重要邮件漏判 | 单独统计假阴性；Beta 后确定可接受阈值 |
| 纠错 | 统计用户纠错率，不代替准确率 |
| 延迟 | 分列排队、调用和回写；CLI 中位目标 3 分钟 |
| 可靠性 | 失败率目标 2%；未知动作结果单列 |
| 留存 | 第 4 周仍处理邮件，目标 35% |
| 价值 | 自然语言规则使用率目标 40% |

报价、转化与排期均待验证。
原 PRD 假设买断 29–49 美元或年费 19–29 美元。
本轮不建立支付、试用限制或收费功能。

## 推荐与重评

先证明安全整理闭环，再验证用户是否愿意持续使用。
若 Apple Events 定位不可靠，先做只读建议版本。
若 Harness 安全模式不可满足，停止该 Adapter 上线。
这些降级都需要重评 P0 范围与宣传。
