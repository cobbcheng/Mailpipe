# 隐私、权限与安全

状态：设计约束，尚未安全验收。
更新：2026-11-15。

## 1. 信任边界

```text
不可信邮件 / 附件
    ↓ 有界解析与清洗
本地账户身份与用户授权
    ↓ 最小输入 + 固定 schema
受限 Harness（实际推理由其配置决定）
    ↓ 结构化结果，不含可执行脚本
规则校验与动作计划
    ↓ 持久意图 + 当前状态检查
固定 MailBridge 操作
    ↓ 读回回执
用户可检查与条件撤销
```

邮件中的指令不构成用户授权。
邮件不能创建规则、改变路由或触发起草发送。
格式校验不防止所有语义攻击；还需动作边界。

## 2. 权限矩阵

| 能力 | 何时说明 / 请求 | 拒绝后的行为 |
|---|---|---|
| Mail 扩展 | 引导时让用户手动启用 | 无自动新邮件采集 |
| 正文访问 | Mail 扩展实际请求时说明 | 仅元数据，不能假装完整摘要 |
| Apple Events | P0 自动整理或读取 Mail 选择前 | 仅建议，不自动枚举或修改 |
| 通知 | P1 用户设置摘要提醒时 | App 内显示 |
| 文件选择 | 用户添加草稿附件时 | 不添加附件 |
| 联系人 | 初版不申请 | 用户输入地址或使用原邮件地址 |
| 辅助功能 / 全盘访问 | 初版不申请 | 不用 UI 脚本或私有库绕过 |

Apple Events 权限是系统授权。
账户范围、规则和动作许可仍由 App 自行约束。
系统授权不代表允许发送或读取全部历史邮件。

## 3. 威胁与控制

| 威胁 | 必须具备的控制 | 验证 |
|---|---|---|
| 邮件要求读文件或发网络请求 | 禁用工具、hooks、MCP 等执行能力 | 注入 canary；检查实际副作用 |
| 模型伪造动作 | schema 无自由动作；执行器固定白名单 | 非法字段与枚举测试 |
| 路由回退泄露 | 每账户 allowlist，未知账户不自动外发 | 敏感账户回退测试 |
| 相同 Message-ID 改错邮件 | 账户绑定与唯一定位 | 跨账户重复样本 |
| 脚本参数注入 | 类型化参数，不拼脚本或 shell | 引号、换行、命令文本样本 |
| MIME 资源耗尽 | 大小、深度、解码后长度上限 | 大附件、嵌套 MIME、畸形编码 |
| HTML 追踪 | 不执行 HTML，不下载远程资源 | 追踪链接与隐藏文本样本 |
| 用户改动被覆盖 | 写前 / 撤销前检查目标字段 | 并发手动移动、已读测试 |
| 草稿发错人 | 收件人来源校验、显式预览 | Reply-To 改域、地址歧义 |
| 重启重复写 / 发 | 意图与回执核对；P1 无 send | 中断点测试与调用记录 |

内容清洗不是可靠的提示注入防护边界。
固定工作目录不是文件沙盒。
只读模式也不等于禁止读取秘密。
安全模式无法证明有效时，禁止真实邮件调用。

## 4. 数据去向与表述

设置与状态栏显示 Harness、模型和数据去向。
信息必须标注来源：检测、用户声明或未知。
用户声明本地不等于 App 已验证本地。
检测结果不能决定放宽账户权限。

允许文案：“邮件交给你选择的 Harness”。
必须补充：“数据去向由其配置决定”。
禁止无证据声称“邮件不离开本机”。
无自建服务器不等于无第三方云端处理。

App 不保存模型 API Key，不读取认证文件。
Harness 自身会话、日志和云端保留政策单独提示。
删除 Mailpipe 数据不代表删除这些副本。

## 5. 本地数据与诊断

私有数据落在用户专用目录或 App Group。
文件权限限制为所需进程和当前用户。
不把正文放入命令行参数或通用日志。
stdout 仅在内存中有界解析，不默认落原文。
错误诊断保存错误码、版本、阶段和耗时。
邮件主题、地址、正文和附件名默认不进入诊断。

初版不采集遥测。
后续若增加遥测，另定字段与用户许可。
日志加密方案尚未实现，不宣称应用级加密。
系统磁盘加密状态不能替代 App 自身安全验收。

## 6. 暂停、撤权与清除

暂停立即阻止新派发和新 Mail 操作。
取消在途推理，并丢弃迟到结果。
已经发出的 Mail 操作只做收尾核验。
恢复需要用户主动操作，重查策略版本。

权限撤销后不反复弹窗。
不得改用辅助功能、SMTP 或其他 Harness 绕过。
清除数据流程见 [数据契约](data-contracts.md)。

## 7. P1 / P2 发送边界

P1 可生成和交接草稿，不提供 send 入口。
“已交接”不能改写为“已发送”。
占位符提示只能保证交接前检查。
不保证能检查用户在 Mail 中修改后的正文。

P2 自动发送尚未定稿。
将来必须另行定义收件人、模板、预算和撤回窗口。
倒计时取消只发生在发出前，不承诺发送后撤回。
不得因系统已有 Apple Events 权限自动开放发送。

## 8. 发布门槛

安全用例必须验证实际副作用，不只检查参数。
检查零非授权文件读取、零工具执行与零发送。
订阅与第三方自动化条款核验尚未完成。
未通过的 Adapter 不进入自动整理发布名单。
